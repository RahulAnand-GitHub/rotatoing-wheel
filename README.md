# 🎨 Rotating Color Wheel

This project is a simple and interactive rotating color wheel built using **HTML** and **CSS**. When you hover over the wheel, it smoothly spins; once the cursor leaves, it resets to its original position.

## 🔗 Live Demo

👉 [View it on GitHub Pages](https://rahulanand-github.github.io/rotatoing-wheel/)

## 🚀 Features

- Pure HTML and CSS — no JavaScript needed
- Smooth rotation animation on hover
- Auto-reset to original position when hover ends
- Responsive and minimal design
